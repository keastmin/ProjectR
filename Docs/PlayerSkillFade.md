# 스킬 돌진 페이드

`DemoScene 1`의 **Skill Director**를 선택하고 Timeline 창에서 `SkillTimeline`을 엽니다.
**Player Opacity** 트랙은 플레이어 모델의 Animator에 연결되어 있으며, 몸체와 무기를 함께 투명하게 만듭니다.

## 타이밍 조절

- **Dash Fade** 클립의 위치/길이: 투명해지는 전체 구간입니다. 클립 밖에서는 원래 불투명 머티리얼을 사용합니다.
- **Blend In Duration** / 클립 왼쪽 위 핸들: 원래 모습에서 투명해지는 시간입니다.
- **Blend Out Duration** / 클립 오른쪽 위 핸들: 투명 상태에서 다시 나타나는 시간입니다.
- **Opacity**: 클립 중앙의 불투명도입니다. `0`은 완전히 투명, `0.2`는 20% 불투명, `1`은 원래 모습입니다.
- Blend 곡선으로 가속/감속을 조절할 수 있으며, 타임라인을 스크럽해 바로 미리 볼 수 있습니다.

기본값은 60fps 기준 **42~55프레임(0.70~0.9167초)**입니다.
42~45프레임에 사라지고, 45~51프레임에 투명 상태를 유지하며, 51~55프레임에 나타납니다.
돌진 이동 키의 시간을 바꿀 때는 페이드 클립도 함께 옮기거나 늘려 주세요.

## 동작 및 검증

페이드는 모델/Animator/Renderer를 끄지 않고 현재 모델의 URP Lit 머티리얼을 임시 복제합니다.
클립 종료, 스킬 중단, 디렉터 정지/파괴, 오브젝트 비활성화 시 원래 머티리얼로 복구합니다.
일시정지와 히트스톱은 현재 투명도를 유지합니다. 원본 머티리얼 에셋에는 변경을 저장하지 않습니다.
`Player Fade.mat`은 투명 렌더링용 템플릿이며, 트랙 참조를 통해 빌드에도 포함됩니다.
다른 셰이더의 모델로 교체할 때는 해당 셰이더의 투명 렌더링 지원을 확인해야 합니다.

Unity 메뉴 **Tools > Combat > Validate Player Opacity Timeline**으로 독립된 미리보기 씬에서
페이드, 역방향 스크럽, 중단/재사용, 히트스톱, 클립 편집과 머티리얼 복원을 검증할 수 있습니다.
